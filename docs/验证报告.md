# V1.0 验证报告

验证日期：2026年10月13日。界面名称V1.0，接口版本1.0.0。

## 结果

32项Python自动测试全部通过；JavaScript样本衔接测试及四份浏览器脚本语法检查通过。实际Chromium界面检查覆盖单样本六通道投影、候选对六通道对比和GLM比较、整体与单通道空间、12个簇总结、4个TPE试验及模型激活。页面未捕获JavaScript异常。1500×1000桌面与390×844移动布局均检查，移动布局无横向溢出。

| UMAP | 实际umap-learn拟合及transform；缓存不受验证向量变化影响；预测采用保存向量；参考文件改变时拒绝旧运行 |

## 验证边界

以上采用明确标记的合成数值夹具及预计算原始向量。浏览器GLM使用响应替身；14次调用仅是测试计数，不代表实际API已运行。软件正常运行时不会用此替身替代真实GLM。

本环境未配置用户研究数据、原论文权重、SciBERT检查点和有效智谱密钥，未执行相应真实数据/服务验证；也未在原生Windows系统上测试启动。使用者需在本机核对这些文件、模型维度、划分和服务配置。

本版NumPy训练及TPE是真实数值实现，但不是原论文全部PyTorch脚本的逐项复现。UMAP不用于计算候选机制距离；整体图不混合六套独立PCA。LLM引用结构检查不等同于物理事实审核。

完整机器可读结果与依赖版本见validation_report.json。复核命令见README。
