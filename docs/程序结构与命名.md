# V1.0 程序结构

| 文件 | 功能 |
| --- | --- |
| `server.py` | 本机 HTTP 服务、输入文件保存、结果下载 |
| `app/core.py` | 材料特征校验、预测调用、Top-5 检索、候选机制配对 |
| `app/prediction_engine.py` | 本版 NPZ 模型和旧 PyTorch 模型的推理 |
| `app/training_workflow.py` | 训练配置、保存划分后的运行状态、完整流程与模型激活 |
| `app/task_manager.py` | 数据及训练子进程、持久任务记录和日志 |
| `app/mechanism_analysis.py` | GLM 初始化、证据预览、两阶段分析、引用检查和导出 |
| `science/dataset_manager.py` | 联合 JSON/Excel 解析、跨表对齐、自动和手动划分 |
| `science/reference_encoder.py` | 冻结 SciBERT 编码、原始向量导入和训练集 PCA |
| `science/neural_network.py` | NumPy MLP、BatchNorm、Dropout、Adam 和余弦损失 |
| `science/training.py` | 固定参数预训练、冻结迁移和分集合评估 |
| `tools/workflow.py` | 训练流程命令行入口 |
| `tools/scaler_converter.py` | 可信旧 joblib 标准化参数转换 |
| `tools/import_previous_workspace.py` | 旧配置和模型路径导入 |
| `tools/inspect_environment.py` | 依赖、版本和非敏感配置检查 |
| `web/app.js` | 通用页面、材料预测和候选筛选 |
| `web/workflow.js` | 数据上传、划分配置、训练状态和日志界面 |
| `web/analysis.js` | 当前预测衔接、机制分析生成和证据追溯 |

本版未继续复制图号脚本，也保留固定训练默认流程，并提供可选TPE优化。需要追溯原文抽取约束时，可查看 `docs/mechanism_extraction_prompt.txt`；软件从抽取后的 JSON 开始工作，不承担原论文全文抽取。

## 新增模块

| 文件 | 功能 |
| --- | --- |
| science/visualization.py | UMAP、原始空间、共同分簇与研究输出复用 |
| science/visual_export.py | 300dpi PNG、SVG、PDF图表导出 |
| science/optimization.py | Optuna TPE、验证目标、试验记录和模型激活 |
| app/exploration_analysis.py | 簇机制解释及候选对两阶段机制比较 |
| app/analysis_jobs.py | 异步空间与比较任务、持久历史和导出 |
| tools/import_analysis_outputs.py | 已生成研究分析产物路径发现 |
| web/visualization.js | 六通道空间、样本投影、配对比较与搜索界面 |
