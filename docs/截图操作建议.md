# V1.0 截图操作建议

建议依次记录概览、数据输入、准备后的 train/val/test 数量、真实训练日志、分集合指标、材料预测、Top-5、机制分析页及整体总结。

使用浏览器或系统截图即可。界面显示的软件名称和版本为「氧化机制表征学习与动力学分析软件 V1.0」。保持足够字号，可单独截图某个通道及其引用条目，避免一张过长截图。

使用合成演示时保留演示标识；要展示训练和研究模型解释，应运行你自己的有效数据、模型和 API 配置，不使用虚构日志替代。

新增页面建议截图：整体六通道UMAP、各通道空间与簇高亮、簇机制总结及来源、预测状态与Top-5标记、候选对六通道比较、通道与整体机制差异、贝叶斯试验结果和验证/测试指标。软件说明书中使用真实界面截图时，由用户自行截图插入。
